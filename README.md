# PMS Admin React

A modern **Property Management System (PMS) admin dashboard** built with React and Vite.  
Scalable state management, efficient data fetching, and responsive UI for managing property operations.

---

## 🚀 Tech Stack

- **React** — UI library
- **Vite** — Fast build tool
- **Redux Toolkit** — Global state management
- **TanStack Query** — Server state & data fetching
- **Axios** — HTTP client
- **Tailwind CSS** — Utility-first styling
- **Ant Design** — UI component library

---

## 📦 Installation

Clone the repository:

```bash
git clone https://gitlab.com/orientalvigourmm/pms-admin-react.git
cd pms-admin-react
```

Install dependencies:

```bash
npm install
# or
yarn install
```

Environment Variables:
Create a .env file in the root directory and add your API base URL:

```bash
VITE_API_BASE_URL=https://api.yourdomain.com
```

Start the development server:

```bash
npm run dev
